# HideMuteSoundboardIcon

A simple plugin for Vencord that hides the muted soundboard icon everywhere

# How to Install plugin

## 1. Install Vencord

You can find out how to install Vencord here: https://docs.vencord.dev/installing/

## 2. Clone this repository into your Vencord plugins directory:
cd Vencord/src/userplugins  
git clone https://github.com/Aristokratichno/HideMuteSoundboardIcon/  

## 3. Reinject Vencord
cd Vencord  
pnpm inject
